# Security Policy

## Supported Versions

Only the **latest release** of ShopForge receives security updates. Previous
versions are not patched retroactively.

## Reporting a Vulnerability

If you discover a security vulnerability in ShopForge, please report it
**privately** to avoid exposing other users:

**Email:** yuntongsoft@outlook.com

Please include:

- A description of the vulnerability
- Steps to reproduce or a proof-of-concept
- The affected version(s)

## What to Expect

- We will acknowledge receipt of your report within a reasonable timeframe.
- We will evaluate the report and determine the appropriate course of action.
- We **do not** offer bug bounties or financial rewards.
- We **do not** guarantee a fix for every report — each case is evaluated on
  its merits and the project's resources.

## Important Notices

ShopForge is provided **"AS IS"** under the terms of the
[ShopForge Commercial License](LICENSE). See Sections 5 (No Warranty) and
7 (Limitation of Liability) for full details.

## Please Do NOT

- Open a public GitHub Issue for a security vulnerability.
- Disclose the vulnerability on social media, forums, or other public channels
  before we have had a reasonable opportunity to address it.
- Perform any testing that could disrupt or degrade production services.
